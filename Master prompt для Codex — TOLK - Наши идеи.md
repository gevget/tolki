# MASTER PROMPT — толк+ЮСТ / «НАШИ ИДЕИ»

Ты создаёшь полноценный production-ready сайт **толк+ЮСТ / «Наши идеи»**.

Это не обычное портфолио агентства и не каталог кейсов.

Это публичная продуктовая лаборатория толк+ЮСТ: проекты, которые команда придумала, исследует, проектирует, прототипирует, собирает в MVP или уже развивает.

Основной смысл сайта:

> Мы не только делаем клиентские проекты. Мы постоянно придумываем собственные продукты, проверяем гипотезы, проектируем интерфейсы, собираем MVP и исследуем новые рынки.

# 1. ИСТОЧНИК КОНТЕНТА

В проекте должен находиться исходный документ:

`Проекты (1).docx`

Перед разработкой:

1. Изучи документ полностью.
2. Выдели все продукты.
3. Не придумывай фактов, которых нет в документе.
4. Не копируй длинные внутренние описания дословно.
5. Превращай информацию в короткий web-copy.
6. Старые внутренние заметки, незаполненные бюджеты, вопросы команды, устаревшие исследования рынка и черновые расчёты не выводить на сайт.
7. Не придумывать статус `MVP / Prototype / Live`, если он явно не подтверждён.
8. Архитектура должна позволять позже вручную поменять status каждого проекта в одном data-файле.

Вынеси информацию о проектах в отдельную структуру данных.

Например:

```ts
type Project = {
  id: string
  title: string
  shortDescription: string
  category: string
  stage?: "idea" | "research" | "prototype" | "mvp" | "development" | "live"
  theme: "light" | "dark"
  mediaType: "placeholder" | "screenshot" | "generated" | "hybrid"
  media?: ProjectMedia[]
  highlights: string[]
}
```

Контент не должен быть захардкожен внутри JSX.

# 3. ЦВЕТОВАЯ СИСТЕМА

Не использовать абсолютную шахматку:

`white → black → white → black`.

Это выглядит механически.

Вместо этого использовать **ритм глав**.

Основные поверхности:

```css
--white: #FFFFFF;
--paper: #F5F5F2;
--paper-secondary: #ECECE8;

--black: #090909;
--graphite: #141414;
--graphite-secondary: #1C1C1C;

--text-dark: #0B0B0B;
--text-light: #F5F5F5;

--text-muted-dark: rgba(0,0,0,.56);
--text-muted-light: rgba(255,255,255,.58);
```

Основной светлый фон не обязан быть чисто белым.

Предпочтительный основной light:

`#F5F5F2`

Это даст более дорогой editorial-эффект.

Активный проект должен быть хорошо заметен, но без тяжёлой заливки.

Но переход должен быть спокойным:

`200–350ms`.

Можно также оставить sidebar независимого нейтрального цвета, если смена всего sidebar создаёт визуальный шум.

Выбрать лучший вариант после прототипирования.
